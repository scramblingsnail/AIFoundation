    BERT论文

    BERT是Encoder-Only的架构

    BERT的特点：

    1. Bi-directional Attention 不像使用 Causal Attention Mask 的GPT，BERT的注意力中，每个Token都收到来自其它所有Token的贡献。
    2. Pretrain Objectives BERT在Pretrain阶段的训练目标有：
    3. Next Sequence Classification: BERT输入的是一个句子对，两个句子之间用特殊Token \SEP 隔开。这两个句子或者是顺序关系，或者没有顺序关系。 输入的最开头是一个特殊Token \CLS，在最后层的输出特征中，这个位置的特征起到集合所有信息的作用，该特征可用于分类，例如判断句子对是否有顺序关系（二分类）。
    4. Masked Language Modeling: 随机选择输入序列中的一些Token进行Mask，对于这些被选择的Token，以80%的概率替换为 \Mask 特殊Token，以10%的概率替换为随机Token，10%概率不替换。 BERT需要负责还原出这些被Mask的Token。相应的损失函数是 交叉熵损失函数 （每个Masked Token 都是一个词表大小的分类）。

    为什么 Post-LN 训练不稳定？

    因为在训练初始阶段，Post-LN结构的Transformer在最后一层的梯度值很大，学习率过大的话容易不稳定。因此Post-LN结构的Transformer往往需要进行学习率Warm-up Pre-LN结构的初始梯度值小得多，因此可以去掉该过程。

    RLHF阶段 Reward模型如何训练

    GRPO

    GRPO的本质是更换优势函数的估计方式，在PPO中是使用一个Critic网络来估计状态价值函数，并采用时序差分估计法，具体来说是GAE来估计优势函数。 而在LLM场景下，维护并训练一个同等规模大小的Critic网络成本比较高。因此GRPO去掉了Critic网络，转而采用了类似蒙特卡洛估计法的方法。

    具体来说，对每一个Prompt，生成（一组）多条序列O_i，并使用Reward模型给出相应的打分 r_i，对每一组 r_i，进行标准化（减均值除以标准差）后，作为优势函数值 A_i

    可以每个序列最末尾给一个Reward，也可以采用Reasoning的方式，每条序列分为多个Reasoning阶段，对每个Reasoning部分给一个Reward，某个阶段的优势函数A_i就是该部分后续的Reward之和。

    因此，GRPO的训练目标是 Maximize J(\theta)

    J(\theta) = \frac {1} {G} \sum_{i=1}^{G} |O_i| \sum_{t=1}^{|O_i|} -\beta D_{KL}(\pi_{\theta}||\pi_{ref}) + min(A_i \frac {\pi_{new}(O_{i, t}| O_{i, <t}; \theta)} {\pi_{old}(O_{i, t}| O_{i, <t}; \theta_{old})}, clip(\frac{\pi_{new}(O_{i, t}| O_{i, <t}; \theta)} {\pi_{old}(O_{i, t}| O_{i, <t}; \theta)}, 1 - \epsilon, 1 + \epsilon) A_i)

    其中的KL散度用于约束 当前策略 与 Ref策略之间的差异不要太大。但该 KL散度 求解难度较大，一般采用随机样本 估计 的方式：

    估计KL散度

    K1估计

    D_{KL} (q||p) = E_{x~q} (log \frac {q(x)} {p(x)})
    K1 = log \frac {q(x)} {p(x)} = -log r

    缺点：估计值会出现负值（KL散度最小值为0）,数值波动较大

    K2估计

    K2 = \frac {1} {2} (log \frac {p(x)} {q(x)})^2 = \frac {1} {2} (\log r)^2

    K2估计有偏，但是方差较低；且确保所有样本的值都是正数。

    K3估计

    K3 = \frac {p(x)} {q(x)} - 1 - \log \fac {p(x)} {q(x)} = (r - 1) - \log r

    K3估计是无偏估计且恒大于等于 0。

    因此，可以使用K3估计式去估计 KL散度。
