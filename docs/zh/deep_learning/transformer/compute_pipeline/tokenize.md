# **Tokenizer**

## **待解决问题**
提炼出文本中的基本单位，将文本按这些基本单位划分。

最朴素的划分方式是按字符、单词进行划分。常用的分词方式是 sub-word 分词。

## **子词分词算法**

### **Byte-Pair Encoding (BPE)算法**
BPE算法类似于聚类方法，从一个初始词表（Unicode字符）开始，通过分析单词语料库中的字符对（子词对）出现的
频次，不断地将出现频次最高的字符对加入词表作为新的子词。

**问题定义**

给定包含若干段文本的语料库，根据该语料库生成对应的子词表。

**算法流程**

1. 数据预处理：将所有文本按单词、符号进行划分，记录每个单词、符号的出现频次，与初始划分方式（逐字符划分）。
2. 子词表扩充：
> 1. 遍历该单词语料库，记录每个可能的字符对，以及出现的频次。选择频次最高的字符对作为新子词，加入到子词表中。
> 2. 根据新加入的子词，更新所有单词的划分方式。
3. 重复 2 直到满足停止条件（如子词表数量达到一定值）

### **WordPiece算法**
Google的算法，未开源。但据猜测类似于BPE，不过将选择新子词的标准从频次替换为了：

$$
Score("u"+"n") = \frac{N("un")} {N("u") \times N("n")}
$$

这样可以优先选择更独特的子词组合。
