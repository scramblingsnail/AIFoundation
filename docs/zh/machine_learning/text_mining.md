# **文本挖掘**

## **待解决问题**
从文本数据中挖掘特征。

## **TF-IDF 单词-文本矩阵**
Term-Frequency: 指某个单词在一段文本中出现的频率。
Inverse Document Frequency: 指出现过该单词的文本占总文本数的比例的倒数，再取对数

$$
TF-IDF = \frac {n_{w_i \_ in \_ text_j}} {N_{text_j}} * log \frac {Num_{text}} {Num_{w_i in text}}
$$

得到的单词-文本矩阵 尺寸为 $C \times N$ ， $C$ 和 $N$ 分别为 词表大小 与 文本总数。

## **Embedding模型 分词算法**
从语料库中统计出最合适的 sub-word 词表。

### **Byte-Pair Encoding**
类似于聚类。

给定多段文本组成的语料库。

1. 文本标准化 + 将文本以单词、符号为基本单位拆分，构成以单词为基本单位的语料库（如存为哈希表），并记录每个单词/符号的出现频次。
2. 初始词表是 Unicode 的字符，类似于聚类，遍历单词语料库，记录所有 字符对（byte-pair）出现的频次。选择频次最高的字符对，将它们作为新的子词加入词表。
3. 加入新子词后，将单词语料库中各单词的符合要求的拆分方式进行合并。
4. 重复 寻找新子词 → 合并 的过程，直到满足停止条件（如词表大小达到某一数量）
